A simple Spring Boot application that helps users remember where they placed their items.
The user can store items along with their location and later search for them when needed.

✨ Features

Add an item along with its stored location

Search items by name

View all stored items

Update or Delete entries (Full CRUD)

Persistent storage using Spring Data JPA

🛠️ Tech Stack

Backend
  Java 8+
  Spring Boot
  Spring Web
  Spring Data JPA
  MySQL/MongoDB (configurable)

Frontend
  HTML
  CSS
  Javascript
  Bootstrap
